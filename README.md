### Subscribing on iPhone
The `.ics` file is published via GitHub Pages at:

```
https://jnysteen.github.io/KoegeKommuneHolidayCalendar/koege_skoleferie.ics
```

To subscribe on an iPhone so the events show up in the Calendar app and stay up to date automatically:

1. Open **Settings** → **Calendar** → **Accounts**.
2. Tap **Add Account** → **Other**.
3. Under *Calendars*, tap **Add Subscribed Calendar**.
4. Paste the URL above into the **Server** field and tap **Next**, then **Save**.

The calendar will appear in the Calendar app and iOS will periodically refresh it from GitHub Pages, so future updates to this file show up without resubscribing.
